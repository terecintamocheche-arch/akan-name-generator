# Akan Name Generator

## Description
This project is an Akan Name Generator that calculates a user's Akan name based on their date of birth and gender.

## Author
Terecinta Mocheche

## Features
- Enter day, month and year of birth
- Select gender
- Displays the corresponding Akan name

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Use
1. Enter your birth date.
2. Select your gender.
3. Click **Generate Akan Name**.
4. Your Akan name will be displayed.
